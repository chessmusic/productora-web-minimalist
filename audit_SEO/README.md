# Paquetes de Auditoria SEO

La plantilla original `03-auditoria-seo.md` es una buena base tecnica para analizar una web, pero como producto comercial conviene dividirla en niveles. La version original intenta cubrirlo todo: meta tags, headings, velocidad, schema, Open Graph, sitemap, robots, imagenes, enlaces y dashboard. Eso funciona bien como auditoria completa, pero puede ser demasiado amplia para una auditoria basica de 150 EUR.

Por eso se han creado tres paquetes separados:

## Base

Carpeta: `base/`

Auditoria rapida para detectar bloqueos claros. Pensada para webs pequenas, revision previa a campanas o clientes que necesitan saber por donde empezar.

- Precio orientativo: 150 EUR.
- Alcance: hasta 5 URLs.
- Foco: indexacion, metadatos, H1, alts, schema basico, sitemap, robots, CTA y prioridades.
- Entregable: diagnostico breve con top 5 acciones y checklist.

## Standard

Carpeta: `standard/`

Auditoria recomendada para la mayoria de empresas. Ya entra en contenido, intencion de busqueda, conversion, enlaces internos y oportunidades long-tail.

- Precio orientativo: 400 EUR.
- Alcance: hasta 15 URLs.
- Foco: tecnica, on-page, arquitectura, contenidos, conversion, schema y roadmap de 30 dias.
- Entregable: informe completo con prioridades y oportunidades de contenido.

## Premium

Carpeta: `premium/`

Auditoria estrategica para webs con varios servicios, idiomas, landings, blog o campanas activas.

- Precio orientativo: 900 EUR.
- Alcance: hasta 60 URLs.
- Foco: SEO tecnico, arquitectura, contenidos, landings, Google Ads, conversion, medicion, competidores y roadmap de 90 dias.
- Entregable: plan estrategico completo con matriz keyword-intencion-URL y backlog priorizado.

## Recomendacion Comercial

Usar `standard` como paquete principal. Es el mas equilibrado: suficientemente profundo para aportar valor real, pero sin convertirse en una consultoria larga.

Usar `base` como puerta de entrada o diagnostico inicial.

Usar `premium` cuando haya inversion real en SEO/Ads, varios idiomas, muchas paginas o necesidad de roadmap.
